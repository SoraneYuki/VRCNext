**2026.40.2**

**Linux Base Support**

This update does not add anything new to the Windows version.

VRCNext now has basic Linux support. The Linux port includes the core features of VRCNext, but some features are not available yet, including:

* VR Overlay
* FrameShot
* Space Flight
* KikitanXD
* Voice Fight
* Discord Presence
* Avatar Scaling
* OSC Tool
* YouTube Fix
* Custom Chatbox

Most of these features are planned to be added in future updates.

**Important**

The AppImage has been tested on the latest versions of Ubuntu and CachyOS with KDE Plasma. I cannot guarantee that it will work correctly on every Linux distribution.

Please report Linux-related bugs on the Discord. Do not report them here on GitHub.
